# The Long Track - Testbuilds

Hier liegen nur die **Testbuilds** von *The Long Track*, einem Koop-Survival auf einem
fahrenden Zug. Der Quellcode ist nicht öffentlich.

## Spielen

1. **Launcher laden:**
   [LongTrackLauncher.exe](https://github.com/KMDEV-Marcel/TheLastTrack/releases/latest/download/LongTrackLauncher.exe)
   (kleine Datei, keine Installation nötig).
2. Starten. Windows warnt beim ersten Mal ("Der Computer wurde durch Windows geschützt"),
   weil die Datei nicht signiert ist: **Weitere Informationen → Trotzdem ausführen**.
3. **Installieren** lädt den neuesten Build (rund 1 GB) nach
   `%LOCALAPPDATA%\TheLongTrack`. Später zeigt der Launcher neue Versionen von selbst an.
4. **Steam starten** und einloggen, dann **Spielen**.

## Zu zweit spielen

Beide brauchen denselben Build - der Launcher sorgt dafür, wenn beide auf "Aktualisieren"
gehen. Einer klickt im Spiel **Spiel hosten**, der andere **Spiele suchen** → **Beitreten**.
Oder einladen über das Steam-Overlay (Umschalt+Tab), Einladung annehmen, während das Spiel
läuft.

Im Steam-Profil steht dabei "spielt Spacewar" - das ist Valves Test-App, über die die
Verbindung läuft, solange das Spiel keine eigene Steam-Seite hat.

## Voraussetzungen

Windows 10 oder 11 (64 Bit), eine DirectX-12-Grafikkarte, Steam.
